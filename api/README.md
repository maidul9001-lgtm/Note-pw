# নোটপ্যাডকে Firebase-এর সাথে জোড়া লাগানো

এই `api` ফোল্ডারে দুটি কোড-ফাইল আছে:

| ফাইল | কাজ |
|---|---|
| `firebase-config.js` | আপনার Firebase প্রজেক্টের দুটি মান বসানোর জায়গা (`apiKey`, `projectId`) |
| `sync.js` | লগইন, রেজিস্টার, পাসওয়ার্ড রিসেট ও নোট সিঙ্কের কোড (কোনো লাইব্রেরি লাগে না) |

`index.html`-এর পাশেই এই `api` ফোল্ডার থাকতে হবে। `firebase-config.js`-এ মান না বসালে অ্যাপ "ডেমো মোডে" থাকে, আসলে কিছু পাঠানো হয় না।

## ধাপ ১: Firebase প্রজেক্ট বানান

1. https://console.firebase.google.com খুলে Google অ্যাকাউন্ট দিয়ে ঢুকুন।
2. **Create a project** (বা Add project) চাপুন, একটা নাম দিন (যেমন `mynotepad`)।
3. Google Analytics দরকার নেই, বন্ধ রাখুন। **Create project** চাপুন।

## ধাপ ২: ইমেইল-পাসওয়ার্ড লগইন চালু করুন

1. বাঁ দিকের মেনুতে **Build → Authentication** → **Get started**।
2. **Sign-in method** ট্যাবে **Email/Password** চাপুন।
3. প্রথম সুইচ (Enable) চালু করে **Save** করুন। (Email link বন্ধ থাকবে।)

## ধাপ ৩: Firestore ডাটাবেস তৈরি করুন

1. **Build → Firestore Database** → **Create database**।
2. জায়গা (location) বেছে নিন, বাংলাদেশের কাছের `asia-south1 (Mumbai)` ভালো।
3. **Start in production mode** বেছে **Create** করুন।

## ধাপ ৪: নিরাপত্তার নিয়ম (Rules) বসান

Firestore Database পাতায় **Rules** ট্যাবে সব মুছে নিচের লেখা বসিয়ে **Publish** করুন।
এতে প্রত্যেক ব্যবহারকারী শুধু নিজের নোট পড়তে ও লিখতে পারে, অন্য কেউ পারে না।

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## ধাপ ৫: পুরো Config কপি করে বসান

1. Firebase Console-এ ওপরে বাঁ দিকে গিয়ার আইকন → **Project settings**।
2. **General** ট্যাবে নিচে **Your apps** অংশে ওয়েব আইকন (`</>`) চাপুন।
3. অ্যাপের একটা নাম দিন, **Register app** চাপুন। (Hosting দরকার নেই।)
4. **SDK setup and configuration** থেকে **Config** বেছে নিন। এমন একটা লেখা দেখাবে:

```js
const firebaseConfig = {
  apiKey: "AIza....................",
  authDomain: "my-notepad-12345.firebaseapp.com",
  projectId: "my-notepad-12345",
  storageBucket: "my-notepad-12345.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef123456",
  measurementId: "G-XXXXXXXXXX"
};
```

5. `api/firebase-config.js` খুলে `const firebaseConfig = { ... };` অংশটা মুছে Firebase-এর দেওয়া পুরো অংশটা বসান। বাকি ফাইল (নিচের `window.FIREBASE_CONFIG = firebaseConfig;` লাইনসহ) যেমন আছে তেমন থাকবে।

`apiKey` সবচেয়ে জরুরি। `projectId` ভুল হলেও অ্যাপ লগইনের টোকেন থেকে আসল প্রজেক্ট আইডি নিজেই বের করে নেয়।

## ধাপ ৬: আপলোড ও পরীক্ষা

1. `index.html`, `api` ফোল্ডার (ভেতরের দুই ফাইলসহ) একই জায়গায় আপলোড করুন।
2. অ্যাপ খুলে **মেনু → সিঙ্ক কার্ড → লগইন / রেজিস্টার** চাপুন।
3. রেজিস্টার করলে নিজে থেকে প্রথম সিঙ্ক শুরু হবে। কার্ডে আর "ডেমো" লেখা থাকবে না।
4. দ্বিতীয় ফোনে একই ইমেইলে লগইন করলে নোটগুলো চলে আসবে।

## APK বানালে

GitHub Actions-এর `build-apk.yml` ফাইলে `api` ফোল্ডার `www`-তে কপি করার লাইন আছে। রিপোর মূল ফোল্ডারে (যেখানে `index.html` আছে) `api` ফোল্ডারটাও রাখুন।

## সিঙ্ক যেভাবে কাজ করে

- সিঙ্ক হয়: নোট, ফোল্ডার ও ডাইরি। সেটিংস, ট্রাশ আর কাস্টম ফন্ট সিঙ্ক হয় না।
- অ্যাপ খুললে, "এখনই সিঙ্ক" চাপলে, ইন্টারনেট ফিরলে, আর নোট বদলানোর আধা মিনিট পর নিজে থেকে সিঙ্ক হয়।
- দুই ফোনে একই নোট বদলালে যেটা পরে বদলানো সেটা থাকে।
- এক ফোনে নোট মুছলে (ট্রাশে পাঠালে) অন্য ফোন থেকেও চলে যায়।
- ইন্টারনেট ছাড়াও আগের মতো লেখা যায়, নেট এলে সিঙ্ক হয়।
- সেটিংসের সিঙ্ক কার্ডে "কতটি নোট synced", শেষ সিঙ্কের সময় আর দরকারি নোটিশ (যেমন "৩টি পরিবর্তন সিঙ্ক বাকি", "ইন্টারনেট নেই") দেখায়।

## খরচ

Firebase-এর Spark (বিনামূল্যে) প্ল্যানে প্রতিদিন প্রায় ৫০ হাজার পড়া আর ২০ হাজার লেখার সীমা আছে। সিঙ্ক শুধু বদলানো নোট পড়ে ও লেখে, তাই সাধারণ ব্যবহারে এর অনেক নিচে থাকে।

## সমস্যা হলে

| বার্তা | কারণ |
|---|---|
| ইমেইল/পাসওয়ার্ড লগইন চালু করা নেই | ধাপ ২ করা হয়নি |
| Firestore ডাটাবেস পাওয়া যায়নি | ধাপ ৩ করা হয়নি |
| অনুমতি নেই | ধাপ ৪-এর Rules বসানো হয়নি, ভুল, বা মেয়াদ শেষ (টেস্ট মোডের `request.time < timestamp.date(...)` নিয়ম ৩০ দিন পর বন্ধ হয়ে যায়)। Rules ট্যাবে সব মুছে ধাপ ৪-এর নিয়ম বসিয়ে Publish করুন |
| API Key ভুল | `firebase-config.js`-এ `apiKey` ঠিকমতো কপি হয়নি |
| ইন্টারনেট সংযোগ নেই | নেট নেই, অথবা API Key-তে ওয়েবসাইট-নিষেধ (HTTP referrer) দেওয়া আছে। অ্যাপ `https://localhost` থেকে চলে, তাই নিষেধ রাখলে এটাও যোগ করুন, না হয় নিষেধ তুলে দিন |
